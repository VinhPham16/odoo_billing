## 6. ⚠️ Gotcha đã gặp (tránh lặp)
1. Seed image Harbor **phải amd64** — nginx lỡ arm64 → `exec format error`. Dùng `docker pull --platform linux/amd64`.
2. `odoo.conf` mount **phải 644** (không 600): user `odoo` trong container (uid khác host) mới đọc được; 600 → `Permission denied` → Odoo bỏ conf, chạy default (`list_db=True` nguy hiểm).
3. `db_password`/`admin_passwd` trong odoo.conf phải `key = value` (space 2 bên `=`): entrypoint đọc bằng `cut -d " " -f3`, thiếu space → rỗng.
4. `psql -U odoo` phải kèm `-d postgres` (không có DB tên `odoo`). Role/slot là object global.
5. `/opt/...` tạo bằng `sudo mkdir` → root → `cat >` lỗi; fix `sudo chown -R $USER:$USER /opt/<dir>`.
6. Volume standby phải **external + trùng tên** `docker volume create`, nếu để compose tự tạo sẽ prefix tên dự án → lệch volume.
7. Standby `primary_conninfo` cần có `password=`; nếu `-R` không ghi → thêm tay vào `postgresql.auto.conf` rồi restart.
